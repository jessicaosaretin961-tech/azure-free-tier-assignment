# Azure Free Tier Account Setup Assignment

## Overview

This project demonstrates the setup of a Microsoft Azure Free Tier environment and basic cloud resource deployment.

## Tasks Completed

- Created an Azure account
- Explored Azure Portal
- Created a Resource Group
- Reviewed Microsoft Entra ID and RBAC concepts
- Selected a deployment region
- Deployed a Storage Account
- Explored Cost Management and Billing

## Region Chosen

South Africa North

## Resource Group

rg-cloud-lab

## Resource Deployed

Storage Account

## Cost Management

Cost Analysis was reviewed to understand cloud spending and monitoring.

## Shared Responsibility Model

Microsoft secures the cloud infrastructure while customers secure their accounts, permissions, and data.
