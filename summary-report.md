# Azure Free Tier Account Setup Summary Report

## Selected Region

I selected South Africa North as my Azure region. This region is geographically closer to Nigeria than many other Azure regions, helping reduce network latency and improve performance.

## Resource Group

A Resource Group named rg-cloud-lab was created to organize and manage Azure resources.

## Resource Deployed

A Storage Account was deployed within the Resource Group. This provided hands-on experience with Azure resource deployment and management.

## Shared Responsibility Model

The Shared Responsibility Model explains how security responsibilities are divided between Microsoft Azure and the customer.

### Microsoft Azure is responsible for:
- Physical security of data centers
- Hardware maintenance
- Network infrastructure
- Cloud platform availability

### The customer is responsible for:
- Managing user access
- Protecting account credentials
- Configuring cloud resources securely
- Managing and protecting stored data

For the deployed Storage Account, Microsoft secures the underlying infrastructure while I manage access and usage of the storage resource.
